# WOD TIMER PWA

무료로 설치 가능한 Chelsea / EMOM 타이머. 기존 iOS 프로젝트의 WOD TIMER 아이콘을 사용합니다.

## 기능
- 기본 Chelsea: 30분 / 60초 간격 / 풀업 5, 푸시업 10, 에어스쿼트 15
- 운동 이름, 시간, 간격, 준비 시간, 종목/횟수 편집
- 시작/일시정지/초기화, 3·2·1 카운트다운, 라운드 알림음, 지원 기기 진동
- 지원 기기 화면 켜짐 유지, 프리셋 저장/불러오기
- 운동 달력(31일까지), 수동 완료 체크, 기록 및 JSON 백업/복원
- 서비스 워커를 통한 설치 후 오프라인 캐시

## 무료 배포: GitHub Pages
1. GitHub에서 **새 Public 저장소**를 만듭니다. 예: `WOD-TIMER-PWA`.
2. 이 폴더의 **파일 전체를 저장소 최상위(root)** 에 업로드합니다. ZIP 자체를 업로드하지 마세요.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Pages가 게시되면 `https://사용자명.github.io/WOD-TIMER-PWA/` 링크를 공유합니다.
5. 아이폰 Safari에서 링크를 열고 공유 → 홈 화면에 추가 → 웹 앱으로 열기 → 추가.

> 기존 iOS 저장소는 Private이므로 그대로 유지하고, PWA만 별도 Public 저장소로 배포하는 방법을 권장합니다. GitHub Pages의 무료 공개 호스팅 조건에 맞춰 공개 저장소를 사용합니다.

## 주의사항
- 브라우저의 백그라운드/잠금 화면에서는 JavaScript 타이머와 알림음이 중단될 수 있습니다. 화면을 켠 채 사용하는 것을 전제로 합니다.
- 웹앱에서 다른 앱의 음악 볼륨을 직접 낮출 수 없습니다.
- 진동 및 Screen Wake Lock은 기기/브라우저 지원에 따라 작동하지 않을 수 있습니다.
- 기록은 사용자 기기에 로컬 저장되며 다른 사용자에게 자동 공유되지 않습니다. 앱 데이터 삭제 시 기록도 사라질 수 있으므로 JSON 백업을 사용하세요.
- 이번 버전은 실제 아이폰 실기기에서 검증하지 않은 초안입니다.
